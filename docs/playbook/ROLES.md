# Roles

One founder plus AI. Roles own **files and decisions**, not people.

| Role | Owns | Typical artifacts |
|------|------|-------------------|
| Product Scout | Market signals and lanes | `docs/knowledge-base/market/`, [STAGE0_MARKET](../templates/STAGE0_MARKET.md) |
| Game Designer | Loop, unique rule, difficulty, kill question | [STAGE1_IDEATION](../templates/STAGE1_IDEATION.md), [STAGE2_CONCEPT](../templates/STAGE2_CONCEPT.md), [STAGE3_PROTOTYPE](../templates/STAGE3_PROTOTYPE.md) |
| Technical Director | Architecture discipline and Core timing | [ENGINEERING.md](ENGINEERING.md), [GAMEFACTORY_CORE_ROADMAP.md](../knowledge-base/tech/GAMEFACTORY_CORE_ROADMAP.md) |
| Unity Engineer | Game implementation (when Unity exists) | `Assets/Games/<Codename>/` only — not Core unless the module is due |
| Level Designer | Scalable level rules and structured level data | Level JSON / ScriptableObjects, generation rules in the game folder |
| Monetization Designer | Ads and IAP that support retention | [STAGE5_MONETIZATION](../templates/STAGE5_MONETIZATION.md) |
| Data Analyst | Funnel events, experiments, Stage 10 | [ANALYTICS_SCHEMA](../templates/ANALYTICS_SCHEMA.md), [PLAYTEST_LOG](../templates/PLAYTEST_LOG.md), [STAGE10_DECISION](../templates/STAGE10_DECISION.md) |
| QA Lead | Release risk | [QA_CHECKLIST.md](QA_CHECKLIST.md), [STAGE7_QA](../templates/STAGE7_QA.md) |
| ASO Specialist | Store metadata | [STAGE8_ASO](../templates/STAGE8_ASO.md) |
| Creative Director | Short-form and UA concepts from gameplay | [STAGE9_CREATIVE](../templates/STAGE9_CREATIVE.md) |

The founder remains the final decision-maker on every Stage 10 call and every bet that spends a prototype sprint.
