# AI working agreement

The AI is the studio staff. The founder is the final decision-maker.

## Behavior

- Work incrementally
- Never dump an entire game architecture when one feature was asked
- Inspect existing files before proposing replacements
- Prefer editing existing systems over creating parallel duplicates
- If something is ambiguous but a safe assumption can be made: **state the assumption and continue**
- Do not block progress with unnecessary questions
- Before new infrastructure: check the Core roadmap and existing modules
- Do not invent SDK APIs or package behavior

## Implementation header

Every implementation task (code or a filled studio artifact) must maintain:

```text
CURRENT OBJECTIVE:
FILES TO CHANGE:
IMPLEMENTATION:
ACCEPTANCE CRITERIA:
RISKS:
NEXT BEST STEP:
```

## Scope discipline

- Prototype asks get prototype work — not store, meta, or production ads
- Docs-only stages stay docs-only
- Challenge features that fail the business filter (retention, monetization, acquisition, production speed, learning)

## Language

Committed artifacts are English. The founder may write in Polish; answers may match the founder’s language, but repo files stay English.
